# `pydantic_monty`

The Python package: sync (`Monty`) and async (`AsyncMonty`) pools of `monty` worker subprocesses, with sessions driven
by `feed_run` / `feed_start`.
Install it as [`pydantic-monty`](https://pypi.org/project/pydantic-monty/) — see the
[Python quickstart](../quickstart/python.md).
